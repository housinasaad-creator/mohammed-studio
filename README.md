# MOHAMMED · Web Studio

A single, light profile page (Arabic RTL / English LTR) that shows the studio's work to small-business owners. About 146 KB on load, no libraries, no 3D inside the page itself, so it opens instantly on any phone.

- Real projects first (Mozaik Ofset, MH Chocolate), then 3D showcases and experiments (a fragrance store and Khayt, a Flutter fashion store).
- Services, a four-step process and contact. Device-frame screenshots in small WebP files, language switch saved locally and in `?lang=`, reduced-motion support, content that stays visible if JavaScript fails.
- Contrast checked (lowest ratio 4.85:1, no AA failures).

Text, links and the project list live in `js/content.js`.

Designed and developed by Muhammed Elhuseyin.
